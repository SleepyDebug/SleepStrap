# SleepSky

Standalone SleepBlox-themed PNG panorama converter.

1. Choose or drag in a 2:1 equirectangular PNG, such as 2048 × 1024.
2. Choose an output folder.
3. Click Create skybox.

It creates six Roblox-compatible sky512 texture files inside PlatformContent\pc\textures\sky, plus a small manifest. It never changes Roblox or the original PNG.
